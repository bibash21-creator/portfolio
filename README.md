## 🛠️ How I built this

I tried to keep things modern and efficient. Here’s the "recipe" for this site:

- **Framework**: Next.js (App Router) — for that snappy, SEO-friendly performance.
- **Styling**: Tailwind CSS — for making things look good quickly and consistently.
- **Animations**: Framer Motion — to make the transitions feel smooth and natural.
- **Backend-ish**: Resend — handling my contact form so you can actually reach me.
- **3D Magic**: @react-three/fiber — because the web is better in 3D.

## 🚀 Want to run it locally?

If you want to poke around the code or see how I set things up:

1.  **Grab the code**: `git clone https://github.com/bibash21-creator/portfolio.git`
2.  **Step inside**: `cd portfolio/portfolio`
3.  **Install the gear**: `npm install`
4.  **Set up your secrets**: Create a `.env.local` file and add your `RESEND_API_KEY`.
5.  **Go live**: `npm run dev`

Then just head over to `localhost:3000` and say hi!
